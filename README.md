# 🚀 OmniLLM - Advanced AI Knowledge Base

OmniLLM is a highly customized version of AnythingLLM, optimized for high-performance local document intelligence and multi-model orchestration.

## 🌟 Custom Enhancements
- **Optimized Local Performance**: Tweaked server configurations for faster document indexing.
- **Branding Overhaul**: Integrated into the OmniAI ecosystem for a unified user experience.
- **Enhanced Documentation**: Streamlined setup guides for rapid deployment.

## 🛠 Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: Prisma, Vector DBs
- **AI**: Integration with various LLM providers

## 📦 Quick Start
1. Clone the repository.
2. Run `npm install` in both `/server` and `/frontend`.
3. Start the server and frontend.
